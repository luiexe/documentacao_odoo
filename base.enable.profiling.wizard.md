# Enable profiling for some time — `base.enable.profiling.wizard`

**Ordenação padrão:** `id`

---

## Campos Principais

- `id` **(integer)** — ID 🔒 readonly
- `duration` **(selection)** — Enable profiling for
  > Opções: `minutes_5` (5 Minutes), `hours_1` (1 Hour), `days_1` (1 Day), `months_1` (1 Month)
- `expiration` **(datetime)** — Enable profiling until
- `create_date` **(datetime)** — Created on 🔒 readonly
- `write_date` **(datetime)** — Last Updated on 🔒 readonly
