# CRM Tag — `crm.tag`

**Ordenação padrão:** `id`

---

## Campos Obrigatórios

- `name` **(char)** — Tag Name ⚠️ obrigatório

## Campos Principais

- `id` **(integer)** — ID 🔒 readonly
- `color` **(integer)** — Color
- `create_date` **(datetime)** — Created on 🔒 readonly
- `write_date` **(datetime)** — Last Updated on 🔒 readonly
