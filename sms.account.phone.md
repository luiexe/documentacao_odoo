# SMS Account Registration Phone Number Wizard — `sms.account.phone`

**Ordenação padrão:** `id`

---

## Campos Obrigatórios

- `account_id` **(many2one)** — Account ⚠️ obrigatório → `iap.account`
- `phone_number` **(char)** — Phone Number ⚠️ obrigatório

## Campos Principais

- `id` **(integer)** — ID 🔒 readonly
- `create_date` **(datetime)** — Created on 🔒 readonly
- `write_date` **(datetime)** — Last Updated on 🔒 readonly
