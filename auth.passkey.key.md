# Passkey — `auth.passkey.key`

**Ordenação padrão:** `id desc`

---

## Campos Obrigatórios

- `name` **(char)** — Name ⚠️ obrigatório
- `credential_identifier` **(char)** — Credential Identifier ⚠️ obrigatório
- `public_key` **(char)** — Public Key ⚠️ obrigatório

## Campos Principais

- `id` **(integer)** — ID 🔒 readonly
- `sign_count` **(integer)** — Sign Count
- `create_date` **(datetime)** — Created on 🔒 readonly
- `write_date` **(datetime)** — Last Updated on 🔒 readonly
