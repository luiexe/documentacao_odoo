# Timesheets Leaderboard Tip — `hr.timesheet.tip`

**Ordenação padrão:** `id`

---

## Campos Obrigatórios

- `name` **(char)** — Tip Name ⚠️ obrigatório

## Campos Principais

- `id` **(integer)** — ID 🔒 readonly
- `create_date` **(datetime)** — Created on 🔒 readonly
- `write_date` **(datetime)** — Last Updated on 🔒 readonly
