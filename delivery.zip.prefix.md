# Delivery Zip Prefix — `delivery.zip.prefix`

**Ordenação padrão:** `name, id`

---

## Campos Obrigatórios

- `name` **(char)** — Prefix ⚠️ obrigatório

## Campos Principais

- `id` **(integer)** — ID 🔒 readonly
- `create_date` **(datetime)** — Created on 🔒 readonly
- `write_date` **(datetime)** — Last Updated on 🔒 readonly
