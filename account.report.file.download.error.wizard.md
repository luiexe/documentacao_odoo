# Manage the file generation errors from report exports. — `account.report.file.download.error.wizard`

**Ordenação padrão:** `id`

---

## Campos Principais

- `id` **(integer)** — ID 🔒 readonly
- `actionable_errors` **(json)** — Actionable Errors
- `file_name` **(char)** — File Name
- `file_content` **(binary)** — File Content
- `create_date` **(datetime)** — Created on 🔒 readonly
- `write_date` **(datetime)** — Last Updated on 🔒 readonly
