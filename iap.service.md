# IAP Service — `iap.service`

**Ordenação padrão:** `id`

---

## Campos Obrigatórios

- `name` **(char)** — Name ⚠️ obrigatório
- `technical_name` **(char)** — Technical Name ⚠️ obrigatório 🔒 readonly
- `description` **(char)** — Description ⚠️ obrigatório
- `unit_name` **(char)** — Unit Name ⚠️ obrigatório
- `integer_balance` **(boolean)** — Integer Balance ⚠️ obrigatório

## Campos Principais

- `id` **(integer)** — ID 🔒 readonly
- `create_date` **(datetime)** — Created on 🔒 readonly
- `write_date` **(datetime)** — Last Updated on 🔒 readonly
