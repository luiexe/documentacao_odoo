# Message — `mail.message`

**Ordenação padrão:** `id desc`

---

## Campos Obrigatórios

- `message_type` **(selection)** — Type ⚠️ obrigatório
  > Used to categorize message generator 'email': generated by an incoming email e.g. mailgateway 'comment': generated by user input e.g. through discuss or composer 'email_outgoing': generated by a mailing 'notification': generated by system e.g. tracking messages 'auto_comment': generated by automated notification mechanism e.g. acknowledgment 'user_notification': generated for a specific recipient
  > Opções: `email` (Incoming Email), `comment` (Comment), `email_outgoing` (Outgoing Email), `notification` (System notification), `auto_comment` (Automated Targeted Notification), `out_of_office` (Out-of-office Message), `user_notification` (User Specific Notification), `sms` (SMS), `snailmail` (Snailmail), `whatsapp_message` (WhatsApp)

## Campos Principais

- `id` **(integer)** — ID 🔒 readonly
- `subject` **(char)** — Subject
- `date` **(datetime)** — Date
- `body` **(html)** — Contents
- `model` **(char)** — Related Document Model
- `res_id` **(many2one_reference)** — Related Document ID
- `is_internal` **(boolean)** — Employee Only
  > Hide to public / portal users, independently from subtype configuration.
- `email_from` **(char)** — From
  > Email address of the sender. This field is set when no matching partner is found and replaces the author_id field in the chatter.
- `author_avatar` **(binary)** — Author's avatar
- `incoming_email_to` **(text)** — Emails To
- `incoming_email_cc` **(char)** — Emails Cc
- `outgoing_email_to` **(char)** — emails To
- `pinned_at` **(datetime)** — Pinned
  > Datetime at which the message has been pinned
- `reply_to_force_new` **(boolean)** — No threading for answers
  > If true, answers do not go in the original document discussion thread. Instead, it will check for the reply_to in tracking message-id and redirected accordingly. This has an impact on the generated message-id.
- `message_id` **(char)** — Message-Id 🔒 readonly
  > Message unique identifier
- `reply_to` **(char)** — Reply-To
  > Reply email address. Setting the reply_to bypasses the automatic thread creation.
- `email_layout_xmlid` **(char)** — Layout
- `email_add_signature` **(boolean)** — Email Add Signature
- `create_date` **(datetime)** — Created on 🔒 readonly
- `write_date` **(datetime)** — Last Updated on 🔒 readonly
