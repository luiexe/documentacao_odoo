# Wizard to select PDF documents from the Documents app to sign — `sign.import.documents`

**Ordenação padrão:** `id`

---

## Campos Obrigatórios

- `selected_document` **(many2one)** — Selected Document ⚠️ obrigatório → `documents.document`

## Campos Principais

- `id` **(integer)** — ID 🔒 readonly
- `create_date` **(datetime)** — Created on 🔒 readonly
- `write_date` **(datetime)** — Last Updated on 🔒 readonly
