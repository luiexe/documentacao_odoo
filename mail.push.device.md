# Push Notification Device — `mail.push.device`

**Ordenação padrão:** `id`

---

## Campos Obrigatórios

- `partner_id` **(many2one)** — Partner ⚠️ obrigatório → `res.partner`
- `endpoint` **(char)** — Browser endpoint ⚠️ obrigatório
- `keys` **(char)** — Browser keys ⚠️ obrigatório
  > It's refer to browser keys used by the notification:  - p256dh: It's the subscription public key generated by the browser. The browser will            keep the private key secret and use it for decrypting the payload - auth: The auth value should be treated as a secret and not shared outside of Odoo

## Campos Principais

- `id` **(integer)** — ID 🔒 readonly
- `expiration_time` **(datetime)** — Expiration Token Date
- `create_date` **(datetime)** — Created on 🔒 readonly
- `write_date` **(datetime)** — Last Updated on 🔒 readonly
