# Save favorite GIF from Tenor API — `discuss.gif.favorite`

**Ordenação padrão:** `id`

---

## Campos Obrigatórios

- `tenor_gif_id` **(char)** — GIF id from Tenor ⚠️ obrigatório

## Campos Principais

- `id` **(integer)** — ID 🔒 readonly
- `create_date` **(datetime)** — Created on 🔒 readonly
- `write_date` **(datetime)** — Last Updated on 🔒 readonly
